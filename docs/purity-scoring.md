# 纯洁度参考评分

参考 [egress-observatory 的公开规则](https://github.com/BlackSlience-Reaper/egress-observatory/blob/master/SCORING.md)，仅实现本项目已接入的数据项。基础分 92，没有额外加分，不代表安全概率，也不能与原项目完整评分直接比较。

| 项目 | 规则 |
| --- | --- |
| 威胁情报报告提及 | OTX 1–2 / 3–9 / ≥10 份报告，分别扣 3 / 6 / 10 分。白名单及已确认误报扣 0 分；报告提及不等于确认恶意。 |
| 欺诈 / 风险分 | 当前使用 IPQuery 原始风险分 R（0–100）。按原规则单一 IPQuery 来源的 0.5 权重修正，综合风险为 `0.6R + 0.4 × 0.5R = 0.8R`，扣 `0.8R × 0.3 × 重叠修正`。 |
| 代理 / VPN / Tor | 来源明确表态后的加权命中率为 E。VPN 为 `24E`，代理为 `26E`，较小的一项减半，另加 `40 × Tor 命中率`，这一类最多扣 50 分。 |
| 机房 / 云服务 | `15 × 机房加权命中率`。用于网络类型参考，不表示恶意。 |
| 垃圾滥用记录 | SFS 命中后扣 `3 + 9 × 置信度/100`，最近 90 天另加 2，最多 12。缺失置信度时不加该部分，并标明缺失。 |
| 滥用标记 | ipapi.is 明确标记当前 IP 存在滥用时扣 10 分。 |

标签权重为 IPQuery 0.8、Blackbox 0.5、ipapi.is 0.9。SFS 明确观测到 Tor 时计 4 票；其未返回 Tor 字段不参与投票。没有返回的字段不参与分母。公司网络滥用评分、Blackbox 分类置信度不当作当前 IP 的风险分。

重叠修正为 `1 − 0.4 × max(VPN 命中率, 代理命中率, Tor 命中率, 0.5 × 机房命中率)`，减轻风险分与匿名 / 机房标记重复计分。欺诈 / 风险分、OTX、垃圾滥用记录及滥用标记合称滥用类，最多扣 40 分。每项保留一位小数，总分最低 0；达到类别上限时页面说明封顶。

至少两个来源完整返回 VPN、代理、Tor、机房字段，并且取得 IPQuery 风险分、SFS 记录及 OTX 报告数，才生成总分。未配置的选配来源不阻止其他来源提供这些证据；非公网地址不出总分。数据不足时页面仅展示已知扣分，隐藏总分、空扣分项和失败来源，接口中保留诊断信息。不会因隐藏失败来源而降低评分所需的证据标准。

本项目尚未将 ASN 信誉、邻居信誉、DNS 黑名单、连接实测纳入评分。新增来源时必须核对目标地址、字段含义和底层情报来源，避免同库重复计分。
